# SaaS Knowledge Base Documents

This folder previously contained bundled PDF/HTML documents for the SaaS Knowledge Base.
These documents are now **fetched at deploy time** by the KB synchronizer Lambda
(`ecs_fargate_app/lambda_kb_synchronizer/kb_synchronizer.py`) and uploaded directly to the
KB S3 bucket during the weekly sync or initial deployment.

## Notes

- The CyberArk APN blog post was intentionally excluded (partner-owned content).
- All documents are AWS-authored content fetched from public URLs into the deployer's own KB bucket.
- Metadata sidecar files (`.metadata.json`) are generated by the Lambda alongside each document.
